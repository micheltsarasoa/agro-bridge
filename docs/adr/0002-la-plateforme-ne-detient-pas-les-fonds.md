# La plateforme ne détient pas les fonds

L'acheteur paie le groupement directement par mobile money avant le chargement et saisit la référence de transaction ; l'agent confirme la réception. Détenir des fonds pour un tiers peut exiger un statut de monnaie électronique, et les API des opérateurs exigent une entité légale marchande, deux obstacles pour un pilote dans 4 à 6 mois.

## Consequences

- Pas de séquestre en v1 : le risque est couvert par la confirmation de réception, les photos, le score de fiabilité et la médiation.
- L'abonnement B2B remplace la commission, qu'on ne pourrait pas prélever à la source.
- Intégration API et séquestre : roadmap après la création de l'entité.
